Thông Số Kết Nối & Bảo Mật Hệ Thống

Cơ sở dữ liệu: Microsoft SQL Server 2022 (web_thoi_trang - Chuẩn 3NF)

Backend Engine: ASP.NET Core 10 Web API + Dapper ORM (Parameterized SQL & Stored Procedures)

Kiểm soát truy cập (RBAC): Session-backed role validation trên từng API (admin vs nhan_vien vs khach_hang) + trạng thái khóa tài khoản tức thì.

Bảo mật Mật khẩu & Giao dịch: Argon2id Salted Hash, Anti-CSRF Synchronizer Token, Idempotency-Key chống trùng đơn COD/QR.
