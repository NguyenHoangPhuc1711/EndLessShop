Thông Số Kết Nối & Bảo Mật Hệ Thống

Cơ sở dữ liệu: Microsoft SQL Server 2022 (Linux Container Engine)

Database Name: web_thoi_trang (Chuẩn 3NF - 6 bảng nghiệp vụ + 1 bảng phiên)

Backend Engine: ASP.NET Core (.NET 8/9 LTS) / Node.js Express Runtime

Giao dịch Đơn hàng: dbo.order_checkout có khóa sp_getapplock & UPDLOCK, HOLDLOCK chống tranh mua sản phẩm cuối.

Bảo mật Mật khẩu: Argon2id Salted Hash (MemoryCost: 64MiB, TimeCost: 3)

Chống tấn công: Anti-CSRF Synchronizer Token, Rate Limiting đa tầng theo IP và Account ID.
